# Global Retail & Customer Segmentation Analysis

## Project Overview
This project analyzes Global Superstore retail data to understand sales performance and customer purchasing behavior.

## Tools & Technologies
- Python (Pandas, Matplotlib)
- SQL (MySQL)
- Microsoft Power BI
- CSV Dataset

## Project Objectives
- Analyze sales by category and region
- Examine monthly sales trends
- Perform RFM (Recency, Frequency, Monetary) analysis
- Segment customers based on purchasing behavior
- Summarize customer count, total sales, and average customer value

## Key Findings
- Lost Customers represent the largest customer segment.
- Champions have the highest average customer value.
- At Risk customers represent an opportunity for customer retention strategies.

## Project Structure
- `data/` — Dataset and exported analysis results
- `python/` — Python analysis and customer segmentation
- `sql/` — SQL queries
- `powerbi/` — Power BI dashboard
- `screenshots/` — Dashboard screenshots

## Objective
To derive meaningful business insights from retail data and support data-driven decision-making.
